# Платежная Система на Блокчейне

Этот смарт-контракт предоставляет полную функциональность для проведения различных финансовых операций в сети Ethereum, включая единоразовые платежи, покупки продуктов, отправку пожертвований (донатов) и настройку подписок с регулярными платежами.

## Архитектура системы

Система состоит из четырех основных компонентов:

1. **PaymentSystem** - основной контракт для управления платежами
2. **PaymentLibrary** - библиотека для работы с платежами
3. **SubscriptionManager** - библиотека для управления подписками
4. **IERC20** - интерфейс для взаимодействия с токенами ERC20

## Основные функции

### Управление платежами

- Покупка продуктов
- Отправка пожертвований (донатов)
- Настройка подписок с регулярными платежами
- Просмотр истории платежей

### Особенности системы

- Поддержка ETH и токенов ERC20
- Комиссия с настраиваемым процентом
- Возможность освобождения от комиссии определенных адресов
- Безопасные переводы средств

## Инструкция по использованию

### Для пользователей

#### 1. Установка предпочитаемого токена (для платежей токенами ERC20)

```solidity
// Укажите адрес токена ERC20, который хотите использовать для платежей
платежнаяСистема.setPreferredToken(адрес_токена);

// Не забудьте также одобрить разрешение на использование токенов
токен.approve(адрес_платежной_системы, сумма);
```

#### 2. Покупка продукта

```solidity
// Для платежа в ETH:
платежнаяСистема.purchaseProduct{value: сумма_в_wei}(
    адрес_продавца,
    "идентификатор_продукта",
    сумма_в_wei,
    true // используется ETH
);

// Для платежа токеном ERC20:
платежнаяСистема.purchaseProduct(
    адрес_продавца,
    "идентификатор_продукта",
    сумма_в_токенах,
    false // используется токен
);
```

#### 3. Отправка пожертвования (доната)

```solidity
// Для платежа в ETH:
платежнаяСистема.makeDonation{value: сумма_в_wei}(
    адрес_получателя,
    "сообщение_поддержки",
    сумма_в_wei,
    true // используется ETH
);

// Для платежа токеном ERC20:
платежнаяСистема.makeDonation(
    адрес_получателя,
    "сообщение_поддержки",
    сумма_в_токенах,
    false // используется токен
);
```

#### 4. Настройка подписки

```solidity
// Создание подписки с оплатой в ETH:
bytes32 идентификатор = платежнаяСистема.createSubscription{value: сумма_в_wei}(
    адрес_поставщика_услуг,
    "идентификатор_плана",
    сумма_в_wei,
    период_в_днях,
    true // используется ETH
);

// Продление подписки:
платежнаяСистема.renewSubscription{value: сумма_в_wei}(
    идентификатор_подписки
);

// Отмена подписки:
платежнаяСистема.cancelSubscription(
    идентификатор_подписки
);
```

#### 5. Получение информации о платеже

```solidity
(
    адрес_плательщика,
    адрес_получателя,
    сумма,
    использует_eth,
    адрес_токена,
    время_создания,
    статус,
    тип_платежа,
    метаданные
) = платежнаяСистема.getPayment(идентификатор_платежа);
```

#### 6. Получение информации о подписке

```solidity
(
    адрес_подписчика,
    адрес_поставщика,
    идентификатор_плана,
    сумма,
    интервал_в_днях,
    время_начала,
    время_следующего_платежа,
    использует_eth,
    активна
) = платежнаяСистема.getSubscription(идентификатор_подписки);
```

### Для администраторов

#### 1. Настройка комиссий

```solidity
// Установка адреса для сбора комиссий
платежнаяСистема.setCommissionWallet(новый_адрес_кошелька);

// Установка процента комиссии (в сотых долях процента, например 100 = 1%)
платежнаяСистема.setCommissionPercentage(процент_комиссии);

// Освобождение от комиссии
платежнаяСистема.setNoCommissionAddress(адрес_пользователя, true);
```

## Деплой системы

1. Сначала задеплойте библиотеки:
   - PaymentLibrary
   - SubscriptionManager

2. Затем задеплойте основной контракт PaymentSystem, указав:
   - Адрес кошелька для сбора комиссии
   - Процент комиссии (в сотых долях процента)

```solidity
constructor(address _commissionWallet, uint256 _commissionPercentage)
```
