# Финансовая Система на Блокчейне

Этот смарт-контракт предоставляет функциональность для проведения различных финансовых операций в сети Ethereum, включая единоразовые платежи, покупки товаров, отправку поддержки (донаты) и настройку регулярных платежей.

## Архитектура системы

Система состоит из четырех основных компонентов:

1. **FinancialOperator** - основной контракт для управления транзакциями
2. **TransactionHelper** - библиотека для работы с транзакциями
3. **RecurringPaymentService** - библиотека для управления регулярными платежами
4. **ITokenStandard** - интерфейс для взаимодействия с ERC20 токенами

## Основные функции

### Управление транзакциями

- Покупка товаров
- Отправка поддержки (донаты)
- Настройка регулярных платежей
- Просмотр истории транзакций

### Особенности системы

- Поддержка нативной валюты (ETH) и токенов ERC20
- Комиссия с настраиваемым процентом
- Возможность освобождения от комиссии определенных адресов
- Безопасные переводы средств

## Инструкция по использованию

### Для пользователей

#### 1. Установка токена по умолчанию (для платежей токенами ERC20)

```solidity
// Укажите адрес токена ERC20, который хотите использовать для платежей
финансоваяСистема.setDefaultToken(адрес_токена);

// Не забудьте также одобрить разрешение на использование токенов
токен.approve(адрес_финансовой_системы, сумма);
```

#### 2. Покупка товара

```solidity
// Для платежа в ETH:
финансоваяСистема.purchaseItem{value: сумма_в_wei}(
    адрес_продавца,
    "идентификатор_товара",
    сумма_в_wei,
    true // используется ETH
);

// Для платежа токеном ERC20:
финансоваяСистема.purchaseItem(
    адрес_продавца,
    "идентификатор_товара",
    сумма_в_токенах,
    false // используется токен
);
```

#### 3. Отправка поддержки (доната)

```solidity
// Для платежа в ETH:
финансоваяСистема.sendSupport{value: сумма_в_wei}(
    адрес_получателя,
    "сообщение_поддержки",
    сумма_в_wei,
    true // используется ETH
);

// Для платежа токеном ERC20:
финансоваяСистема.sendSupport(
    адрес_получателя,
    "сообщение_поддержки",
    сумма_в_токенах,
    false // используется токен
);
```

#### 4. Настройка регулярного платежа

```solidity
// Создание регулярного платежа в ETH:
bytes32 идентификатор = финансоваяСистема.startRecurringPayment{value: сумма_в_wei}(
    адрес_получателя,
    "код_тарифа",
    сумма_в_wei,
    период_в_днях,
    true // используется ETH
);

// Продление регулярного платежа:
финансоваяСистема.renewRecurringPayment{value: сумма_в_wei}(
    идентификатор_платежа
);

// Отмена регулярного платежа:
финансоваяСистема.cancelRecurringPayment(
    идентификатор_платежа
);
```

#### 5. Получение информации о транзакции

```solidity
(
    адрес_отправителя,
    адрес_получателя,
    сумма,
    использует_eth,
    адрес_токена,
    время_создания,
    статус,
    тип_транзакции,
    данные
) = финансоваяСистема.getTransaction(идентификатор_транзакции);
```

#### 6. Получение информации о регулярном платеже

```solidity
(
    адрес_клиента,
    адрес_продавца,
    код_тарифа,
    сумма,
    период_в_днях,
    время_создания,
    время_следующего_платежа,
    использует_eth,
    активен
) = финансоваяСистема.getRecurringPayment(идентификатор_платежа);
```

### Для администраторов

#### 1. Настройка комиссий

```solidity
// Установка адреса для сбора комиссий
финансоваяСистема.setFeeCollector(новый_адрес_сбора_комиссий);

// Установка процента комиссии (в сотых долях процента, например 100 = 1%)
финансоваяСистема.setFeeRate(процент_комиссии);

// Освобождение от комиссии
финансоваяСистема.setFeeExemption(адрес_пользователя, true);
```

## Деплой системы

1. Сначала задеплойте библиотеки:
   - TransactionHelper
   - RecurringPaymentService

2. Затем задеплойте основной контракт FinancialOperator, указав:
   - Адрес кошелька для сбора комиссии
   - Процент комиссии (в сотых долях процента)

```solidity
constructor(address _feeCollector, uint256 _feeRate)
```

## Безопасность

- Все средства проходят через смарт-контракт с проверками безопасности
- Используйте проверенные контракты токенов ERC20
- Регулярные платежи можно в любой момент отменить
- Только администратор может менять настройки комиссий
